# 🛒 Retenção e Fidelidade no Varejo

> Previsão de churn e otimização de programas de fidelidade com IA. Identifica clientes em risco e personaliza ofertas que aumentam recompra e ticket médio.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/varejo-churn-fidelidade/

[![Setor](https://img.shields.io/badge/Setor-Varejo-blue)]() [![IA](https://img.shields.io/badge/IA-Machine%20Learning-green)]() [![Demo](https://img.shields.io/badge/Demo-Interativa-orange)]() [![Dados](https://img.shields.io/badge/Dados-CSV%2FExcel-success)]()

## 📊 Resultados-chave (KPIs)
**+27%** Retenção · **+34%** Recompra · **+18%** Ticket · **4.8x** ROI

## 🧠 Tecnologias de IA
Machine Learning · Uplift · Churn

## ✨ O que faz
- Score de churn por cliente
- Oferta personalizada
- Otimização de fidelidade
- Aumento de recompra
- Reativação inteligente

## 🗄️ Fonte de dados real
[CRM + programa fidelidade](https://www.gov.br/mdic) — bases de entrada e resultados disponíveis para download em CSV/Excel no app.
